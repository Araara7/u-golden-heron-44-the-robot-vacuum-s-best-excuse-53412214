One line, 106 characters: the funniest excuse a robot vacuum gives for missing a spot, written for the [make.fun](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214) bounty "The Robot Vacuum's Best Excuse".

> I didn't miss that spot. My sensors scanned it twice and classified the dust as a pet, so I left it alone.

## How it works

`main.py` (Python 3, stdlib only, deterministic) writes the entry to `/output/entry.txt`. The gate requires 1–140 UTF-8 characters; the entry is 106.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
